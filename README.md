# Lystra ✦

A prettier way to think before you shop. Lystra is a minimalist monthly shopping planner that helps you save things you want, see what they cost, and plan purchases intentionally.

## Features

- Monthly shopping lists
- Budget and planned-spending tracking
- Need / Want / Maybe filters
- Product links
- Purchase tracking
- Optional “why do I want this?” note
- Local browser storage — no account required
- Responsive editorial-style UI

## Built with

HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Deploy

This project can be hosted for free with GitHub Pages.

## Project

Built as a vibe-coded portfolio project focused on simple UX, visual design and practical everyday use.
